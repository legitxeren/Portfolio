ROHIT KUMAR PORTFOLIO

Files:
- index.html — main portfolio
- style.css — original visual/animation system
- emergency.html — Assistive Walking Stick project detail
- cv.html — CV viewer
- assets/rohit-profile.jpeg — provided profile photo
- assets/Rohit_Kumar_CV.pdf — provided CV

Run locally:
1. Open this folder in VS Code.
2. Install/use the Live Server extension.
3. Right-click index.html -> Open with Live Server.

Or from a terminal in this folder:
  python -m http.server 5500
Then open http://localhost:5500
